About & help

About NovaShop

NovaShop is an educational ecommerce demo built twice: as a monolith and as microservices behind an API gateway. Both versions serve this same storefront.

Products and orders are kept in memory and reset whenever the server restarts. No real payments are taken and no real goods are shipped.

Frequently asked questions

How do I place an order?

Add items to your cart, open the cart, continue to checkout and enter your name and delivery address.

Do I need an account?

No. Orders are remembered on this device, and you can look any order up by its ID on the My orders page.

Is payment collected?

No. This is a demo, so checkout only records the order.

Why did my order disappear?

Demo data lives in memory and is cleared when the services restart.

How many of one item can I buy?

Up to 10 per order line, subject to available stock.

Contact

This is a demo store, so there is no live support. Questions about the project belong in its GitHub repository.
